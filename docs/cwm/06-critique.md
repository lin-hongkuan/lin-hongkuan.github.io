# 06｜批判性阅读：哪些已经展示，哪些还没证明？

读新论文最重要的能力之一，是把**方法定义、原型实现、展示结果、科学证据**分开。CWM 的想法有吸引力，但不能因为演示视频很漂亮，就把所有长期开放世界能力都当成已经验证。

## 论文明确展示了什么？

按论文文本，作者提出了三部分：

1. Coding Agent 与可执行、可修改代码共同维护世界状态并推动状态演化；
2. Proxy 用逐帧的粗空间/时间条件，把可执行状态连接到视频模型；
3. 构造游戏与真实视频的对齐 proxy–observation 数据，并微调 MiniMax H3。

论文展示的结果表明：在作者构造的若干场景和条件下，微调后的视频模型**定性上能跟随部分 proxy 指定的实体位置、动作轨迹、场景布局和相机运动，同时生成丰富外观**。论文报告 proxy 来自 coding-agent 扩展的简单交互世界。

这有意义，但与“通用世界模拟器已解决”差很远。

## 论文承认的限制

作者在 §5 明确写出：

- 计算资源有限，训练规模小，生成质量仍有限；
- 尚未实现自回归实时生成；
- Coding Agent 仍难从零可靠实现高度复杂的游戏机制；
- 原型不能证明 Agent 已可自主构建完整开放世界或完整模拟器。

此外，公开仓库没有释放生成 gameplay proxy 所依赖的闭源游戏基础与构造工具。所以外部研究者目前能按公开代码复用的是**特定条件格式和推理流程**，不是从头复现论文全部 agentic world-building pipeline。

## 证据强度：三层不要混为一谈

| 层级 | 例子 | 能支持什么 | 不能直接支持什么 |
|---|---|---|---|
| 架构主张 | “Agent+代码负责演化，视频模型负责观测” | 一个清楚的研究设计 | 不能证明每个组件已经可靠 |
| 工程实现 | 公开 `prepare`/`generate` 可按配置运行 | 指定模型、格式、硬件下的推理实现 | 不能证明训练代码/数据全部公开，或普通 GPU 可复现 |
| 实证结果 | 论文图和视频展示定性条件跟随 | 在展示案例中有可行性证据 | 不能单独证明统计显著、泛化、真实物理或长时因果一致性 |

## 关键问题：什么叫“遵循 Proxy”？

如果角色质心大致跟上轨迹，但手里物体消失、跨帧 ID 换人、物理接触不合理，这算成功吗？需要把“控制效果”拆成可测指标，而不是只看一段视频。

### 建议关注的可测维度

- **实体存在/数量**：指定实体是否出现，是否凭空增删？
- **身份一致性**：同一实体跨窗/遮挡后是否仍是同一个？
- **空间服从度**：框、质心、关键点或分割与 proxy 有多大误差？
- **运动服从度**：速度、方向、轨迹和转向时刻是否跟随？
- **相机服从度**：视点路径和构图变化是否符合约束？
- **交互一致性**：碰撞、抓取、遮挡和物体接触是否前后一致？
- **外观质量**：细节、纹理、自然度如何？
- **长时状态一致性**：续窗后历史事件和属性是否持续？
- **效率**：延迟、显存、每秒视频成本如何？

最后的实验应同时报告自动指标、人类评审或任务成功率，并做误差分析。自动跟踪器可能受风格/域偏移影响，因此不能单指标裁决。

## 应设置哪些对照？

至少要把条件“拆开”，才能知道效果来自哪里：

1. 只有文本，无 proxy；
2. 文本 + 语义 ID；
3. 文本 + 深度；
4. 文本 + 深度 + 语义 ID；
5. 完整 proxy vs 降采样/抽帧 proxy；
6. 固定外观锚点 vs 不重复提供锚点；
7. 重叠续窗 vs 无/不同长度重叠；
8. 简单世界 vs 训练分布外的布局/运动/遮挡；
9. 固定模拟规则 vs Agent 动态修改规则。

比较时要尽量锁定模型、seed、prompt、目标视频、分辨率和推理步数，否则结果可能混杂。

## 因果世界与视频真实感不是一回事

生成模型可以画得“像真的”，但画面上看起来合理并不等于内部规律真实。若拿它训练具身 Agent，还要验证：

- 同一动作在同一状态下结果是否稳定？
- 小幅改变动作，结果是否按预期变化？
- 失败事件和边界条件是否可复现？
- 生成的状态与视频观测是否对应？
- 模拟中的动作/相机/场景分布是否接近部署环境？

若无法答这些问题，系统更适合叫**受控生成环境原型**，而不应轻率称为高保真可用于机器人训练的物理模拟器。

## 你作为学生可以如何评价它

可以用下面六个问题做组会一页总结：

1. **任务**：论文要控制的是视觉生成、世界状态，还是二者？
2. **表示**：状态、规则、关系、proxy 分别显式/隐式在哪里？
3. **接口**：Agent 的世界程序如何变成视频模型能理解的条件？
4. **数据**：proxy 和 RGB 怎样对齐？离线标注依赖什么？
5. **证据**：结果是自动指标、真人评分还是示例视频？对照是否公平？
6. **缺口**：什么环节尚未开源、尚未可复现或尚未实时？

回答这六个问题，就比“这视频很酷”更接近科研阅读。
